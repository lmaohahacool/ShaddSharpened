# Asset provenance

`dist/` is the original browser build of Shaft Additionality (JavaScript + three.js)
and the C# port's runtime asset root. It is **not** generated by this repository:

* Canonical source: <https://github.com/lmaohahacool/Shaft-Additionality2>
  (single commit `a426609` "Add files via upload", `dist/` at the repo root).
  This workspace's git history is stacked on top of that commit, so
  `git log` shows the original upload followed by the C# port.
* The workspace snapshot mechanism drops any directory named `dist`, `bin`,
  `build`, … between sessions. If `dist/` is ever missing again, restore it with
  `git checkout <first-commit> -- dist` or by re-cloning the URL above; the C#
  loaders (`AssetPaths`, `AssetManifest`, `TextureSet`, `ModelLoader`,
  `AudioSystem`) read everything they need from `<exe>/dist`.

## What the game reads from dist/

| Path | Consumer |
| --- | --- |
| `textures/*.png` (34 terrain + 11 item icons + 3 model skins) | `TextureSet` (1024x16 atlas, per-item textures, model skins) |
| `models/{cow,zombie,torch}.json`, `models/manifest.json` | `ModelLoader` (skinned box parts, leg/head pivots) |
| `sounds/{break,place,footstep,hit,eating}.mp3` | `AudioSystem` (decoded once into OpenAL buffers) |
| `sounds/bg_music.mp3` | `AudioSystem` (streamed via MP3Sharp, looped) |
| `*.js` | reference implementation only — the C# port's source of truth for mechanics |

## Placeholder fallback

`tools/gen_placeholder_assets.py` regenerates a complete **stand-in** pack
(procedural 96x96 PNGs, schema-correct model JSONs, synthesised MP3s) so the
port remains runnable and `--selftest` stays green if `dist/` is lost and the
original cannot be fetched. It refuses to run when a real `dist/textures/`
is present unless `--force` is given. Placeholders are recognisable-by-design
flat pixel art, not the original art.
